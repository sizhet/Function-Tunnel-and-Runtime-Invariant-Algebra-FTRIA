# Figure Philosophy

Figures in FTRIA are **shared Runtime Assets**, not document-specific illustrations.

Individual papers reference these figures through cross-links, allowing the repository to function as an interconnected knowledge system rather than a collection of independent documents.

This organization reflects the central philosophy of Runtime Intelligence itself:

> **Knowledge grows through reusable structures and shared Runtime assets rather than isolated components.**
